# Demo script

Use a test profile and fictional phone number. Do not send a real emergency message and never perform a real fall.

1. **Home** — introduce the local-first prototype and prominent SOS control.
2. **Contacts** — add, edit, prioritize, disable, and delete a test emergency contact; show the empty state if appropriate.
3. **SOS** — press and hold, explain foreground location and the user-reviewed SMS composer, then return without sending.
4. **History** — show the trigger, time, location/composer state, and any honest error.
5. **Safety Tools** — demonstrate panic-alarm active/stop state at a considerate volume, fake-call schedule/accept/reject, and explicit audio REC/stop.
6. **Sensor Collection** — select a safe label, show the three-second start countdown, sample count and duration, stop, then open export/share without disclosing personal data.
7. **AI Detection** — enable protection and point out sensor state, model version, live class, fall/phone-drop confidence, and rule result.
8. **Fall policy** — use a development test harness or safe prerecorded/golden input; never stage a dangerous physical fall.
9. **Countdown** — show “Possible Fall Detected,” remaining time, I'M SAFE, and SEND HELP NOW.
10. **False alarm** — choose I'M SAFE and explain the local feedback record.
11. **Escalation** — separately demonstrate SEND HELP NOW or timeout routing to the same EmergencyEngine; do not claim the draft was delivered.
12. **ML evaluation** — show `ai/evaluation/development_metrics.json`, emphasize session-level splitting, rule/LR/RF comparison, fall FPR/FNR, and the synthetic-data warning.

Close with pending physical-device validation and the prototype disclaimer. Add screenshots only after a real run; never fabricate them or results.
